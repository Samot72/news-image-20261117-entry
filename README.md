# Tuesday 17 November 2026 — the world's news in one image

A make.fun entry for [news-image-20261117](https://make.fun/bounty/news-image-20261117): one newspaper
broadsheet front page summing up Tuesday 17 November 2026 — 10 stories across 6 continents, a map of
the stories, and an "Also on" column.

The image (`entry.png`, 1024×1024) is drawn from an HTML/CSS broadsheet rendered to PNG; `main.ts`
copies it to the harness output directory.
